## Домашняя работа по функциям

Решение находится в файле make_report.py

# Требования и зависимости

Для запуска нужен Python 3. Решение использует встроенные возможности Python, установка дополнительных библиотек не требуется.

# Запуск

Поместите входной CSV-файл в папку с make_report.py и откройте терминал в этой папке. По умолчанию программа читает файл Corp_Summary.csv. Другое имя файла можно указать через --input-file.

Первый аргумент report_type (обязательный) - номер типа отчета: 
        1 - Иерархия: департаменты и входящие в них отделы
        2 - Сводка по департаментам: количество сотрудников, диапазон зарплат и средняя зарплата по департаменту
        3 - Сводка по департаментам, записанная в .csv-файл. 
Второй аргумент --input-file (опционально) - название файла для чтения. По умолчанию: Corp_Summary.csv
Третий аргумент --output-file (опционально) - название файла для записи (для отчета типа 3). По умолчанию: salary_report.csv

**Пример запуска:**
python3 make_report.py 3 --output-file report.csv
