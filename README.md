# omd

AAA_HW_3

Домашняя работа по основам язвка Python

Решения задач домашней работы находятся в файле omd.py.

Требования и зависимости

Для запуска нужен Python 3. Решение использует встроенные возможности Python, установка дополнительных библиотек не требуется.

Запуск

Откройте терминал в папке с файлом omd.py и выполните:

python3 omd.py

Все задачи выполняются последовательно. Результаты выводятся в терминал.
